GitHub token

Bình thường không cần làm gì ở đây — token chung đã được lưu sẵn (mã hóa) trong repo và tự mở khi bạn đăng nhập bằng PIN.

Ô dưới chỉ dùng khi muốn ghi đè bằng token riêng của máy này. Xóa token riêng thì tự quay về token chung.
Tạo tại github.com → Settings → Developer settings → Personal access tokens → Fine-grained, chọn đúng repo, quyền Contents: Read and write.
